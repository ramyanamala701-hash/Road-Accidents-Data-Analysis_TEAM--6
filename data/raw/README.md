# Raw data

The active source is `india_road_accidents_dataset.csv`, supplied for this project. It contains 240 rows, 25 fields, and one recorded accident per row. Preserve its values and headers; processing writes only under `data/processed/`, `outputs/`, and `reports/`.

The CSV itself does not establish the source publication, collection method, sampling design, or national representativeness. See `reports/DATA_DICTIONARY.md` for observed fields and values.
